GitHub 雲端部署指引說明

  1. 第一步：註冊 GitHub 並建立儲存庫 (Repository)

    前往 GitHub 官網 註冊帳號，然後建立一個全新的「公開 (Public)」儲存庫，命名為 toyoko-tracker。

  2. 第二步：上傳專案檔案

    將目前資料夾中的所有程式檔案（包含 index.html, style.css, app.js, crawl.js, manifest.json, sw.js, config.json, availability.json...等）上傳到您剛建立的 GitHub 儲存庫中。（.bat 檔可不上傳）

  3. 第三步：建立 Telegram 機器人取得 Bot Token

    在 Telegram 中搜尋並與官方的 @BotFather 開始對話，輸入指令 /newbot。按照指示為您的機器人命名並設定使用者名稱，成功後 @BotFather 會提供一串 **API Token**（例如：123456:ABC-def...），請複製下來。

  4. 第四步：取得您的 Telegram 個人 Chat ID

    在 Telegram 中搜尋並與 @userinfobot 或 @GetIDsBot 開始對話，發送任何訊息給它，它會立刻回覆您的個人 **Id** 數字（例如：987654321），這就是您的 Chat ID，請複製下來。

  5. 第五步：在 GitHub 中設定加密 Secrets

    在您的 GitHub 專案頁面中，點擊上排的 Settings -> 點選左欄 Secrets and variables 中的 Actions -> 點擊 New repository secret，建立以下兩個 Secrets：
    1. 名稱：TELEGRAM_BOT_TOKEN，內容：貼上您的 Bot Token。
    2. 名稱：TELEGRAM_CHAT_ID，內容：貼上您的個人 Chat ID 數字。

  6. 第六步：開啟 GitHub Pages 靜態網站網頁

    在 Settings 頁面點擊左側的 Pages -> 將 Build and deployment 來源設為 Deploy from a branch -> Branch 選擇 main，目錄選擇 / (root) -> 點擊 Save。

  7. 大功告成！

    大約 1 分鐘後，您的網站將部署在 https://[您的GitHub帳號].github.io/toyoko-tracker/！雲端機器人會每 5 分鐘在背景幫您抓取，有房時會直接傳送 Telegram 訊息到您的手機！
